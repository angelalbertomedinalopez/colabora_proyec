# Descripción del proyecto

Este proyecto tiene como objetivo crear una estructura base para un organizador personal que permita gestionar tareas y notas de forma simple y ordenada. Se centra en la organización de información, la planificación de actividades y la práctica de buenas costumbres en control de versiones y trabajo colaborativo.

La intención de esta primera etapa es preparar la base del proyecto para que, en fases posteriores, pueda ampliarse con funciones más avanzadas como registro, edición, consulta y eliminación de tareas.
