# Organizador Personal

## Descripción u Objetivo
Esta aplicación es una estructura base para administrar tareas y notas personales en memoria principal. Su propósito principal en esta etapa es servir como proyecto base para practicar el flujo de trabajo con Git, GitHub y entornos virtuales en Python.

## Tecnologías utilizadas
- Python 3.x
- Visual Studio Code
- Git y GitHub
- Entorno virtual (`venv`)
