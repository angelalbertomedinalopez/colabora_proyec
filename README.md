# Organizador Personal

## Objetivo
Este proyecto es una base para gestionar tareas y notas personales en memoria principal. Su finalidad es practicar el flujo de trabajo con Git, GitHub, Visual Studio Code y entornos virtuales en Python, siguiendo la práctica integradora de la asignatura.

## Tecnologías utilizadas
- Python 3.x
- Visual Studio Code
- Git y GitHub
- Entorno virtual (.venv)
- requests
- python-dotenv

## Pasos de instalación
1. Clonar el repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd organizador_axel
   ```
2. Crear el entorno virtual:
   ```bash
   python -m venv .venv
   ```
3. Activar el entorno virtual:
   - Windows:
   ```bash
   .\.venv\Scripts\activate
   ```
   - Linux/macOS:
   ```bash
   source .venv/bin/activate
   ```
4. Instalar dependencias:
   ```bash
   pip install -r requirements.txt
   ```
5. Ejecutar la aplicación:
   ```bash
   python src/main.py
   ```

## Colaboración
Este repositorio se trabaja siguiendo un flujo de colaboración con ramas y Pull Requests:
- Crear rama de trabajo antes de modificar archivos principales.
- Realizar commits con mensajes claros.
- Enviar cambios al fork o repositorio remoto.
- Crear un Pull Request con descripción del cambio.
- Revisar, aprobar o solicitar cambios antes del merge.
- Sincronizar el repositorio local con `git pull` después del merge.
